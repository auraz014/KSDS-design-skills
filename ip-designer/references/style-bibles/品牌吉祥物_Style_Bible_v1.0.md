# 品牌吉祥物 Style Bible v1.0

## 0. 样本说明

- 原始样本：52 张
- 有效视觉样本：52 张
- 完全重复：未发现
- 表现形式：以 3D 角色渲染、实体玩具感图像为主，也包含角色家族、品牌化展示与少量平面化呈现
- 样本边界：既包含品牌吉祥物，也包含独立角色 IP、角色练习、潮玩式形象和物体拟人角色

因此，本报告提炼的是这批完整图库所代表的“年轻、当代、偏韩式视觉语境的玩具化品牌角色审美”，不应直接解释为所有品牌吉祥物的通用规律。规则描述的是审美判断与设计取舍，不是固定零件表。

## 1. 从样本反推的核心审美

这组图共同追求的不是传统意义上的“标准可爱”，而是：

> 用一个足够简单、可被瞬间读懂的主体形状，叠加一个强识别特征和轻微人格反差，形成适合社交传播与立体衍生的角色。

审美核心可以概括为：

1. **整体概念先于局部零件**：先确定角色最有识别度的整体关系，再决定形体、五官、肢体或配饰，不从固定几何清单机械拼装。
2. **轮廓先于细节**：识别主要来自大形，而不是服装、纹理或复杂配件。
3. **表情简洁但人格范围宽**：五官元素少，却可以通过眼形、眉形、嘴形、视线和面部区域制造机灵、天真、拽、怪、憨、平静或兴奋等不同气质。
4. **玩具化先于写实性**：形态、材质和比例都服务于“像一个可以被做成公仔的角色”。
5. **单一钩子先于平均丰富**：每个角色通常只有一个首要记忆点。
6. **可爱不等于安全无趣**：亲近感是底色，但允许一处克制的怪趣、反差或不完美，让角色摆脱通用萌系模板。

## 2. 形体与比例规则

### 2.1 主体结构

“单一主块体 + 简化附肢”是样本中的高频结构，但不是固定模板。生成时应优先保持大形简洁、重心稳定和玩具化，而不是把所有角色都处理成相同的团块身体与四根短肢。

在同一审美体系内，主体结构应由角色概念自然推导。图库中实际出现的结构范围包括：

1. **头身融合**：脸直接落在一个完整主体上，附肢可隐藏、贴体或从轮廓中长出。
2. **清楚头身关系**：头与躯干分开，但层级少、连接紧凑；头身比例可偏头大，也可接近均衡。
3. **物种特征主导的动物体块**：耳、鼻口、毛团、尾或姿态与主体共同构成动物识别，而不是在通用身体上替换耳朵。
4. **物体或自然形直接成为身体**：果实、火焰、星体、云、食物、器物或品牌符号本身就是角色主形，不再额外套一个标准人形躯干。
5. **包裹、嵌套或前后叠合**：兜帽、外壳、毛团、容器或另一个体块包住或托住主体，形成一个清楚整体。
6. **图形化长肢结构**：在主形足够简单时，可使用偏长、偏细或动作幅度更大的简化肢体，制造轻盈、顽皮或时尚感。
7. **紧凑动物姿态**：坐、趴、蹲、站或经过强烈简化的四足结构都可出现，保留物种特征但不还原真实骨骼。
8. **双角色或家族关系**：同一视觉语法可以通过高矮、体量、颜色或表情形成伙伴与家族，不要求所有成员共享同一身体模板。

附肢关系允许变化：

- 可以无明显手臂、无明显腿，或只强调其中一组附肢。
- 腿可以是直接相连的脚掌、短柱、并拢底座、坐姿支撑，也可以是经过图形化处理的长腿；不统一为四根短圆肢。
- 手臂可以贴体、外伸、下垂、上举、呈鳍状或翼状，也可以由一侧承担动作；允许从极短到偏长的变化，但不进入写实关节和手指结构。
- 附肢既可以是次要结构，也可以在不抢夺一级记忆点的前提下参与轮廓识别。
- 姿态可以稳定站立，也可以奔跑、腾跃、侧倾、环抱、悬浮或与道具互动；动作先服从角色人格，再服从“可爱姿势”。

一组多方案生成时，不要求每个角色完全不同，但也不应把主体结构分配成固定槽位。不要默认“第一个单一主块体、第二个明确头身、第三个坐姿或头身融合”，也不要为了完成结构覆盖而机械地各选一种。

每次生成应重新决定整组方案的构思入口和组合关系：

- 高频结构代表长期出现概率较高，不代表它必须出现在每一组，更不代表必须排在第一张。
- 结构、附肢、表情、姿态和记忆点应根据每个角色概念重新组合，不能固定绑定，例如头身融合不必总是困倦，无手臂不必总是胖圆。
- 同一组里可以出现结构相近的方案，只要它们的角色想法和整体视觉读取不同；也可以出现多个不同结构，但不设置数量配额。
- 方案完成后应打乱展示顺序。序号只表示呈现位置，不表示基础款、标准款、进阶款或实验款。
- 若当前对话中已经生成过同类角色，应主动避开上一组的“序号—结构—表情”对应关系。

### 2.2 比例

该样本不支持固定的统一头身比。更准确的规则是：

- 视觉主体块通常占角色总面积的 55%–85%。
- 附肢相对主体明显缩小。
- 矮、宽、团、敦实仍是高频倾向，但不是默认答案。
- 偏高、偏窄或长肢角色也可以成立，前提是大形简洁、关节被省略、重心清楚，整体仍像图形化玩具而不是动画人物。

### 2.3 轮廓

- 外轮廓应能在小尺寸或剪影状态下识别。
- 常用一处轮廓异常制造记忆点：大耳朵、顶部尖角、星形外缘、方形头、宽帽兜、果梗、特殊发型。
- 圆润是主趋势，但不是绝对禁用尖角；尖角会被软化、加厚或做成玩具形。
- 避免平均分布多个同等强度的轮廓特征。

## 3. 角色原型规则

样本中的角色来源主要分为：

1. **动物再设计**：熊、猫、狗、兔、象、熊猫、水獭等。
2. **物体或自然形拟人**：星星、番茄、火焰、甜甜圈、豆状体、软团块。
3. **混合生物**：保留动物识别点，但整体形状脱离真实动物比例。
4. **抽象人格载体**：不强调物种，通过形状和表情直接表达性格。

选择原型时，应优先考虑它能否自然承载品牌概念，而不是只选择“最可爱的动物”。

### 3.1 默认识别模式与抽象探索模式

动物原型的第一轮生成默认采用**Style Bible 审美优先的稳定识别模式**。这里的“稳定”只表示不过度删除物种识别线索，并不要求使用自然色，也不表示还原真实动物结构。整体概念、玩具化与轮廓识别始终高于解剖完整度。

识别优先模式：

- 默认保留 2–3 个足够强、相互支持的物种线索，例如耳朵的位置与朝向、极简鼻口关系、头脸轮廓、毛发/色块结构或尾部；不要求把真实身体、四肢和姿态同时保留下来。
- 主体必须继续使用 Style Bible 的单一或双重主块体、紧凑玩具比例以及简化或隐藏附肢。不能为了“更像动物”退回完整骨骼、真实胸腹、自然四足比例、分趾爪掌或写实坐姿。
- 物种识别优先通过头脸、耳朵、鼻口、尾巴和大色块完成，而不是通过解剖完整度完成。
- 不为熊、羊、狗等常见动物预设唯一的耳朵、口鼻或身体公式。每次先观察该物种最有区分度的关系，再选择 2–3 个线索进行保留、合并或放大。
- 物种线索可以被几何化、压扁、放大、缩小或融入主体，但不能只靠换耳朵、角或颜色让同一张通用脸扮演不同动物。
- 口鼻区可以简化，但如果删除后会削弱物种识别，则应保留清楚而克制的鼻口关系。
- 若角色需要依靠完整真实身体才像该物种，或已经出现接近真实宠物、公仔化动物模型的胸腔、关节、爪趾和四足结构，应判定为偏离 Style Bible 并重新生成。
- 若角色变成来源不明的物件或其他物种，同样应重新生成。目标是在“极简玩具角色”和“清楚物种线索”之间取得平衡。

完成第一轮方案后，再询问用户是否希望查看**形体更抽象的探索模式**。只有用户明确同意，才进一步使用更激进的减法、切口、负形、轮廓凸起或非自然体块。非自然配色不自动等于形体抽象；只要物种识别稳定、色彩有概念依据，它也可以出现在第一轮。

无论采用哪种模式，都不能把不同动物处理成同一张通用萌系脸，只替换耳朵、角或颜色。

## 4. 面部与表情规则

### 4.1 五官复杂度

- 五官通常由 3–6 个基础图形组成。
- 高频方式包括：点眼、胶囊眼、椭圆眼、弧线眼、半闭眼、粗线眉、小鼻、短线嘴。
- 眼睛并非普遍偏大；大眼与极小点眼同时存在。
- 五官区域通常集中，脸部留白较多。
- 眼型按长期生成倾向控制：约 **65% 使用无眼白的简约眼睛，35% 使用有眼白的图形眼睛**。参考最近 8 个已接受角色，不要求每组三方案固定为 2:1；单组可以是 3:0、2:1 或 1:2，角色适配度高于机械凑比例。
- 无眼白眼睛可使用纯色点眼、胶囊眼、椭圆眼、弧线眼或闭合线眼；有眼白眼睛应保持图形化，使用清楚眼白与纯色瞳孔。
- 所有眼型都禁止高光：不出现白色反光点、玻璃光斑、湿润亮点或玩偶玻璃眼效果。瞳孔和眼球表面保持哑光、纯色、平整。
- 极简不等于统一使用豆豆眼。眼睛可以有睁开、半闭、闭合三种状态，也可以通过瞳孔大小、注视方向、眼距和眼角走势形成差异。
- 眉毛可以省略，也可以使用平眉、短弧眉、轻微上挑或轻微下压；嘴形可以省略或选择短直线、小圆口、浅弧、轻微撇嘴、克制微笑。
- 鼻子不是必选项；如果使用，应与眼睛和嘴共同形成一套清楚的表情语法，而不是机械补齐五官。
- 五官布局允许适度高低、宽窄变化，但左右关系和视线必须稳定、清楚、有意图，避免歪斜、错位和无意识斗鸡眼。

### 4.1.1 五官组合轮换机制

五官多样性不能只靠“眼睛选项很多”来实现。每个方案应先形成一套完整的**脸部签名**：

> 眼型构造家族 + 眼距与尺度 + 面部区域 + 眉眼关系 + 鼻口关系 + 主表情

生成一组方案时执行以下规则：

- 三个方案使用三个不同的标准眼型 ID；五个方案使用五个不同的标准眼型 ID。65%／35% 是跨组滚动倾向，不是每组固定槽位。
- 默认三方案中，`NS01 极小点眼`、`NS02 横向胶囊眼`、`GS01 普通圆眼白`三个高频眼型合计最多出现一个；`M01 短线嘴`、`M06 克制微笑`两个高频嘴形合计最多出现一个。
- 同一组三方案不重复完全相同的“鼻子 ID + 嘴形 ID”。`NM03 圆角三角鼻 + M04 浅 W 嘴`与`NM05 鼻口相连短线 + M04 浅 W 嘴`在视觉上都容易收敛成“深色圆钝鼻子连接左右对称 W 形嘴”，视为同一口鼻语法，组内最多出现一次。
- 同一组不得重复完整的“眼型构造 + 眼距 + 鼻口关系 + 表情”组合。仅改变视线、眉毛角度、瞳孔位置或嘴角方向，不视为新的五官方案。
- 每两个方案的脸部签名至少在三个维度上不同。
- 每次生成前读取 `state/facial-usage-history.json`，把最近 8 个角色作为软参考：当两个方案同样合适时，优先选择近期使用较少的眼型与口鼻组合；若近期出现过的五官最符合当前角色，仍可继续使用，不做硬性禁用。
- 眼型选择必须与角色概念、物种脸部关系和人格相互解释。不能为了完成轮换而随机拼接五官，也不能用歪斜、大小眼或失焦制造差异。
- 允许五官缺省：无嘴、无鼻、仅鼻口合一、脸部色块内置五官、突出软体口鼻、共享眼区等，都可以成为完整脸部语法。

**标准眼型 ID**

- `NS01` 极小点眼
- `NS02` 横向胶囊眼
- `NS03` 短粗线眼
- `NS04` 闭合弧线眼
- `NS05` 挤压／折角符号眼
- `NS06` 一睁一闭的眨眼
- `NS07` 深色主体上的反白图形眼
- `NS08` 眉眼合并图形
- `GS01` 普通圆眼白与小实心瞳孔
- `GS02` 纵向胶囊眼白
- `GS03` 空心环形眼
- `GS04` 半眼睑横向眼白
- `GS05` 连续或近连续眼带
- `GS06` 窄长几何眼白
- `GS07` 经过控制的非对称眼白布局

**标准嘴形 ID**

- `M00` 无嘴；`M01` 短线嘴；`M02` 小圆口；`M03` 浅 U；`M04` 浅 W
- `M05` 纵向开口；`M06` 克制微笑；`M07` 轻微撇嘴；`M08` 轻微偏置曲线；`M09` 克制露舌

**标准鼻口与面部区域 ID**

- 鼻口：`NM00` 无鼻；`NM01` 小点鼻；`NM02` 短胶囊鼻；`NM03` 圆角三角鼻；`NM04` 突出软体口鼻；`NM05` 鼻口相连短线
- 面部区域：`Z01` 中央微小簇；`Z02` 下置；`Z03` 上置；`Z04` 宽眼距；`Z05` 窄眼距；`Z06` 横向眼带；`Z07` 面部色块；`Z08` 深色主体反白区

根据 52 张参考图，可进一步提炼以下五官构造。生成时应从这些真实出现过的视觉语法中选择，而不是反复回到同一种椭圆眼：

**无眼白眼型**

- 极小点眼或小椭圆眼，可配无眉、短平眉或独立小鼻。
- 横向胶囊眼、扁椭圆眼或短粗线眼，适合平静、松弛、冷淡和观察感。
- 闭合弧线眼、平直闭眼、挤压符号眼或 `><` 式闭眼，适合满足、用力、喊叫和强情绪。
- 一睁一闭的眨眼组合，或一侧眼形略有变化的克制不对称组合。
- 深色脸上的反白点眼、反白弧眼或反白几何眼；仍视为无眼白的整体图形眼。
- 眉眼合并的粗线结构，例如短眉直接参与眼睑方向，但必须保持清楚可读。

**有眼白眼型**

- 圆形或椭圆形眼白 + 纯色小瞳孔，可正视或统一侧视。
- 纵向白色胶囊、白色环形或空心椭圆眼，瞳孔可以缩小或省略。
- 横向眼白 + 半眼睑或扁瞳孔，形成冷静、怀疑、傲娇或困倦感。
- 两只眼共用一条连续或近连续的白色眼区，再以瞳孔和眼睑分隔。
- 窄长几何眼白 + 垂直深色内眼，配合角度眉形成认真、强势或小脾气。
- 眼白大小或眼距经过控制的变化，用于惊讶、好奇或荒诞感；不得制造失焦和畸形。

**鼻口构造**

- 无鼻无嘴、仅鼻、仅嘴，都是允许的极简方案。
- 鼻子可为小点、短胶囊、椭圆、圆角三角或突出的软体块。
- 嘴可为短直线、浅 U 形、浅 W 形、小圆口、纵向喊叫口、轻微偏嘴、克制露舌或鼻口相连的短线结构。
- 开口、露舌和喊叫可以出现，但内部结构保持图形化，不绘制写实牙齿、舌头和口腔。

**脸部布局**

- 大面积留白中的微小中央五官簇。
- 五官整体下置或上置，但仍维持稳定重心。
- 宽眼距、窄眼距、纵向鼻口堆叠或横向眼带。
- 五官直接落在主体表面，或放在一个简洁面部色块/面罩区域内。
- 单个痣点、胡须线或脸颊符号可以作为物种或人格信息，但不机械添加。

为避免默认回到中央豆豆眼，生成时优先在以下关系中轮换，而不是按固定顺序覆盖：

- 微小五官簇与大面积留白。
- 宽眼距图形眼与极短鼻口。
- 低位眼睛与突出的软体口鼻块。
- 横向连续眼区或近连续眼带。
- 面部色块、面罩或口鼻区承载五官。
- 反白眼形直接嵌入深色主体。
- 眉眼合并形成一个图形符号。
- 无嘴、仅鼻、鼻口相连或小开口成为表情中心。

- 无奈
- 小脾气
- 傲娇
- 好奇
- 憨厚
- 轻微荒诞

先根据角色任务选择一种主情绪，再添加一个强度较低的次级性格。次级性格可以是正向、中性、轻微负向或怪趣，不应默认选择“困倦、无奈、丧”。推荐保持可亲近底色，但不统一灿烂笑脸，也不统一半闭眼和撇嘴。

可使用的表情组合包括但不限于：

- **明快机灵**：睁开的椭圆眼或弧形眼 + 轻微上扬嘴角。
- **天真好奇**：大小适中的开放眼 + 小圆口或短弧嘴。
- **兴奋期待**：睁开的简约眼 + 克制上扬嘴，避免夸张露齿笑。
- **惊讶困惑**：开放眼或大小适中的有眼白眼 + 小圆口或一高一低的克制眉形。
- **专注认真**：稳定注视 + 平眉或轻微下压眉 + 中性短嘴。
- **得意调皮**：侧向注视或稳定注视 + 单侧轻挑眉 + 轻微不对称嘴形。
- **怀疑观察**：眼距或视线经过控制的偏移 + 一侧眉形变化，不能形成斗鸡眼。
- **满足惬意**：弧线眼或自然睁眼 + 很浅的微笑，不默认等同于困倦。
- **喊叫用力**：挤压符号眼或闭眼 + 纵向小开口，适合短促强烈情绪。
- **冷静怀疑**：半眼睑、横向眼白或扁眼 + 平嘴，视线方向必须一致。
- **空白震惊**：圆眼、环形眼或纵向胶囊眼 + 短直嘴或小圆口。
- **俏皮眨眼**：一睁一闭 + 偏置短嘴或克制露舌，避免媚态和复杂睫毛。
- **认真小脾气**：窄长几何眼 + 角度眉 + 极短嘴，避免攻击性写实表情。
- **害羞温柔**：视线轻微侧移 + 克制小嘴，避免夸张腮红。
- **自信小拽**：稳定注视 + 一侧轻挑眉或短平嘴。
- **呆萌憨厚**：较宽眼距或简单圆眼 + 小鼻与短嘴。
- **平静松弛**：自然睁眼或弧线眼 + 中性短嘴。
- **困倦无奈**：半闭眼 + 平嘴或轻微撇嘴；作为可选方向，而非默认方向。
- **轻微荒诞**：一个经过控制的非常规关系，例如略小瞳孔或轻微不对称嘴形，但不能破坏五官完整性。

### 4.3 表情设计约束

- 主表情必须在缩小后仍可读。
- 不依赖复杂皱纹、眼睫或写实口腔结构。
- 表情变化优先通过眼形、眉角、嘴形改变，避免破坏主轮廓。
- 每个方案只确定一个清楚的主表情，不把多个情绪符号混杂在同一张脸上。
- 一组三个方案默认使用三个不同的主表情类别；除非用户明确要求困倦或丧感，否则最多一个方案使用半闭眼、闭眼或明显下垂嘴。
- 组内不得重复完全相同的“眼睛状态 + 眉形 + 嘴形”组合；差异应清楚但克制，不通过夸张错位制造变化。
- 参考最近 8 个已接受角色的记录维持 65:35 的长期倾向，不为了凑比例牺牲角色概念，也不让每组重复相同的 2:1 配置。
- 同一组方案不得只是改变瞳孔方向或眉毛角度而复用同一套眼睛模具；必须使用不同的标准眼型 ID。
- 一组生成前先建立带标准 ID 的脸部签名表，完成组内去重、高频池检查，并参考近期使用频率，再写入生图提示。正向提示只写当前方案选中的五官，不把候选列表整体放入提示；若组内结果收敛成相同豆豆眼、椭圆眼或短线嘴，应重新生成。
- 如果计划中不同的口鼻组合在生图后都变成“圆钝深色鼻子 + 左右对称 W 形嘴”，即使粗细、材质或立体程度不同，也视为同一口鼻模板回退，需要重新生成。
- 多样性验收以完整脸部读取为准：缩小后如果多个方案仍像同一张脸只换了耳朵、颜色或表情，应判定为同质化失败。
- 生成结果一旦出现眼睛高光、白色反光点或玻璃质感，应视为不符合 Style Profile 并重新生成。

## 5. 色彩规则

样本并不统一低饱和。真实规律是“色彩关系简单”，而不是“颜色一定柔和”：

- 角色通常由 1 个主色主导。
- 辅助色多为 1–2 个，用于脸部、腹部、服装或局部结构。
- 强调色面积较小，用在鼻子、鞋、配件或品牌符号上。
- 同时存在高饱和亮色、柔和粉彩、黑白灰角色。
- 大面积渐变、碎色和复杂花纹较少。

生成时应根据品牌色选择饱和度，不应默认套用马卡龙配色。

辅助色和强调色都是可选项，不是配色完整性的必备条件：

- 只有当颜色来自品牌资产、角色概念、功能区分、材质关系或需要澄清结构时，才增加辅助色或强调色。
- 如果没有明确依据，可以只使用一个主色及其明暗变化，或主色加一个必要的中性色。
- 不为了“更有记忆点”“显得不单调”或让多方案看起来不同而随意加入蓝色、黄色等装饰性色块。
- 无法用一句话解释某个颜色为何存在时，应优先删除它。

动物第一轮生成采用**识别稳定、配色开放**的原则：

- 自然色、经过设计的自然色、品牌色与非自然主色都可以成立；颜色不是物种识别的唯一手段。
- 若使用非自然色，必须能由品牌、人格、角色概念、使用场景或材质解释，并通过耳朵、口鼻、轮廓、毛发体块、尾巴或姿态继续保证物种可读。
- 高饱和黄、绿、橙、蓝、粉与黑白方案在图库中均有出现，可以用于第一轮，但应保持大色块、少颜色和清楚层级。
- 一组多方案可以混合自然色与设计色，也可以围绕一个品牌色建立多个关系；不设固定配色槽位。
- 不以“增加一个蓝色小块”之类的无理由点缀制造差异。颜色变化必须影响角色概念或大色块关系。

## 6. 材质与渲染规则

### 6.1 高频材质

- 哑光软胶
- 轻微绒面
- 充气或柔软塑料感
- 毛绒/短绒
- 少量光滑塑料

### 6.2 表面特征

- 大面干净，无复杂纹理。
- 高光柔和，边缘圆润。
- 毛绒、短绒或植绒是图库中清楚存在的第二材质方向，可以成为角色的主要触感记忆点，但不要求整组统一使用。
- 单个角色通常保持一种主材质；若混合材质，只用来区分一个必要部位或配饰。
- 材质应强化触感和可收藏性，而非追求真实皮肤、毛发或金属细节。

### 6.3 展示方式

- 单角色、正面或轻微三分之四视角最常见。
- 默认使用接近白色、第一眼读作白底的极浅中性灰棚拍背景，视觉明度可参考 `#F7F8F8`，只保留几乎不可察觉的中性接触阴影。
- 避免奶油黄、米黄、象牙白、暖黄、棕褐、脏灰或明显偏深的灰色背景。
- 当白色或浅色角色与背景分离不足时，只轻微加深近白中性灰，而不是把背景调暖或变成明显灰底。
- 只有用户明确指定品牌色背景、具体场景或透明底时才更换默认背景。
- 光线柔和，阴影简单且不染暖色。
- 角色与背景保持明显的明度分离。
- 当呈现伙伴或角色家族时，成员之间应有清楚的尺度、姿态和视线关系，画面仍保持简洁，不变成复杂叙事场景。

## 7. 记忆点设计方法

每个方案优先选择一个“一级记忆点”，可再配一个弱化的二级记忆点：

- 非常规整体轮廓
- 特殊耳朵、角、头顶结构
- 独特面部布局
- 强表情人格
- 品牌物件与身体融合
- 一件高识别配件
- 非常规材质

判断标准：

1. 去掉颜色后仍能识别吗？
2. 缩成头像后仍能看出差异吗？
3. 能否用一句话描述它最特别的地方？
4. 是否容易转化为公仔、贴纸和动态图形？

### 7.1 简单配饰与服饰

第一轮仍优先通过角色本体、五官和轮廓建立记忆点，但当角色身份、行为、品牌或使用场景能够自然导出配饰时，可以直接在第一轮使用。配饰不是“追加轮次专属”，也不是每个角色的必备组件。

同一组中可以自然混合纯本体方案与一件配饰/服饰的方案，不设固定比例或固定序号。配饰应帮助角色像一个有生活和身份的品牌人物，而不是把它变成复杂动画角色。

使用原则：

- 每个方案最多选择 **1 件主要配饰或服饰**；如确有功能需要，可再增加 1 个非常弱的小细节，但不能形成第二个视觉中心。
- 配饰必须来自角色身份、职业、性格、行为、品牌或使用场景，例如帽子表达工作状态、围巾表达陪伴、耳机表达内容或音乐属性。
- 适合的简单形式包括：软帽、便帽、单层兜帽、围巾、领巾、项圈、单片背心、简洁上衣、围兜、简化背带前片、小包、图形化眼镜或高度简化的耳机。
- 服饰优先使用一个完整大色块和少量结构线，不使用复杂印花、多层叠穿、密集口袋、扣带、金属件或写实褶皱。
- 配饰形状应能概括成一个简单几何或一条清楚轮廓，并与角色主体比例协调。
- 颜色沿用角色现有配色系统；没有品牌或概念依据时，不为配饰额外引入新的强调色。
- 配饰不能遮挡主要五官、物种识别特征或破坏小尺寸轮廓。
- 即使移除配饰，角色仍应保持物种识别和基本人格；配饰可以成为记忆点，但不能掩盖一个未完成的角色本体。
- 追加方案中不要求每个角色都穿戴配饰。纯角色方案和配饰方案可以自然混合，不设置固定比例。

不适合的方向：

- 全套复杂制服、礼服或多层街头穿搭。
- 同时出现帽子、眼镜、围巾、包、鞋等多件竞争元素。
- 依靠大段文字、Logo 或复杂图案制造身份。
- 写实的人体剪裁、衣褶、鞋带和五金结构。
- 与角色设定无关、只为了“更丰富”而添加的装饰。

## 8. 品牌转译规则

这批样本的视觉风格很强，但部分案例的“品牌归属”较弱。用于实际品牌项目时，需要补足以下逻辑：

1. 从品牌中提取一个可被形体化的核心概念。
2. 将品牌概念嵌入主体轮廓或一级记忆点，而不是仅贴 Logo。
3. 将品牌色作为色彩系统的一部分，而非机械覆盖全身。
4. 用人格反差形成传播性，但不能与品牌价值冲突。
5. 预先验证头像、全身、表情包、玩偶四种尺度。
6. 当需要角色家族时，用共享的五官语法、材质和色彩逻辑建立亲缘感，用体量、原型、姿态与性格区分成员，避免复制同一身体后只换颜色。

## 9. 避免规则

- 避免写实人体或真实动物比例。
- 避免复杂服装层级和大量小配件。
- 避免同时设置多个竞争性的记忆点。
- 避免无品牌逻辑地套用“大头、小身体、微笑”。
- 避免默认大眼睛；眼形必须服务于人格。
- 避免默认低饱和；饱和度必须服务于品牌和场景。
- 避免无品牌、概念或结构依据的装饰性强调色。
- 避免所有羊都使用白色加低饱和辅助色，也避免所有熊都使用相同棕色方案；自然色和有依据的设计色都应被纳入选择。
- 避免把“高饱和”误解成复杂多色；高饱和方案仍应保持少颜色、大色块和明确主次。
- 避免不同动物只更换耳朵、角或颜色，继续复用同一个头型、口鼻块和五官模板。
- 避免把所有角色默认做成矮胖团块、四根相同短肢和同一套中央豆豆眼。
- 避免为了差异而走向写实长肢、完整人形解剖、复杂动画服装或无法识别物种的极端抽象。
- 避免所有角色都开心微笑，导致人格同质化。
- 避免高频碎纹理、复杂材质和多色渐变。
- 避免只在正面成立、侧面轮廓坍塌的造型。
- 避免直接复刻参考图中的具体角色、配色组合或标志性结构。

## 10. 生成策略

生成时不直接引用现有 IP 名称，也不要求复制某张参考图。应把 Style Profile 转换成抽象设计约束：

1. 先定义品牌概念、角色任务和人格矛盾。
2. 再选择与概念匹配的整体结构和物种/物体原型，确定最少的有效识别线索；不从固定形状、固定肢体和固定脸型菜单机械配装。
3. 只设置一个一级记忆点。
4. 用极简五官表达明确人格。
5. 先用 1 个主色建立角色；自然色、品牌色或有概念依据的非自然色均可，只有存在明确理由时才加入辅助色或强调色。
6. 根据角色身份判断是否需要一件简单配饰或服饰；首轮与追加轮都可使用，但不设置固定配额。
7. 用玩具化材质和简洁棚拍验证立体效果。
8. 输出多个“概念不同”的方案，而不只是换颜色或换配饰。
9. 多方案不使用固定的“胖圆—明确头身—头身融合”顺序；每轮重新组合结构、五官、姿态、色彩与记忆点，并在完成后打乱呈现顺序。

## 12. IP 延展视觉板

当用户说“帮我延展”且当前角色明确时，默认直接设计一张完整视觉板，而不是先询问应用场景。

默认内容：

- 1 个放大的主 IP，作为版面第一视觉中心。
- 6 个较小的表情动作延展，必须同时包含表情变化与身体动作变化。
- 左半区保留醒目的大英文标题，并配合少量小号英文文案和符号装饰建立排版节奏；不标数字。

设计身份：

> 以具备良好平面排版和字体设计能力的年轻韩国设计师视角完成，整体年轻、时尚、简洁，有明确网格、视觉层级和留白。

版式原则：

- 默认优先横版。首选结构为：左半区放大英文标题与主 IP，右半区放置六个延展。大标题要有视觉存在感，但不能挤压主形象。
- 全部元素遵循统一的列网格、行网格、对齐轴、外边距和沟槽，不允许随意散放、拥挤堆叠或无目的重叠。
- 画板四周必须保留明显、均衡的安全留白；标题、主形象和六个延展均不得贴近边缘，内部沟槽也要保持舒适呼吸感。
- 六个延展可采用清楚的 2×3 模块、错层但严格对齐的模块，或宽窄列组合；避免普通九宫格截图感。
- 字体应具有清楚的字号层级、字重关系、字距和对齐逻辑。以一处大英文标题建立版面性格，其余文字保持小而克制。
- 没有角色名称时，只使用 `MOOD SET`、`CHARACTER DESIGN`、`EXPRESSIONS` 等一至两处中性英文微文案，不擅自创造品牌名，不为表情编号。
- 排版颜色从角色已有配色中提取，不另加无意义强调色。
- 可以少量裁切主 IP，但角色、文字和延展之间必须保持舒适留白，不能影响物种和主体识别。

延展一致性：

- 七个角色实例必须保持同一主体轮廓、比例、耳朵/头部结构、基础五官语法、配色、材质和一级记忆点。
- 变化集中在眼形、眉嘴组合、视线、身体倾斜或压缩、耳朵动作、尾巴动作以及必要的简化肢体动作。
- 不为动作方便而给角色重新设计完整手脚，不把延展变成七个不同角色。
- 六个延展不能只是换嘴或换瞳孔方向；需要有可读的情绪和动作差异。
- 所有眼睛继续遵守无高光规则。

如果用户要求多个方案，应变化整张视觉板的网格、构图和字体层级，而不是改变 IP 本体。

## 13. 后续数据补强建议

若此分类的目标是真正的“品牌吉祥物”，下一轮建议补充：

- 同一角色的正侧背三视图
- 同一角色在 Logo、App 图标、包装、活动、空间中的应用
- 表情与动作延展
- 2D 与 3D 的同角色转换
- 明确绑定品牌策略的案例

本次新增的角色家族与品牌化展示已经补强了部分系统关系，但三视图、真实应用与同角色跨媒介资料仍然偏少。继续补充这些内容，才能进一步学习“品牌转译与系统延展”，而不只学习单张角色效果图的审美。
